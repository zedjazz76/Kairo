# Local runtime data

The helper creates `runtime/history` and `runtime/profiles` here as needed. Only this README is tracked in Git.

History contains sanitized snapshots and reviewed-copy content; provider fields are intentionally preserved. Treat it as potentially sensitive. Do not add runtime files to Git, tickets, chat, screenshots, shared drives, or an unapproved backup/synchronization service.

Use the application's History controls to delete selected sessions. Profile labels and notes must not contain PHI, passwords, certificates, or secrets. The application does not encrypt this folder or automatically purge old history.
