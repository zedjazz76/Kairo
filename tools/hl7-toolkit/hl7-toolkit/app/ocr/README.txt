Local OCR payload for Image Sanitize PHI review assistance.

This directory contains the browser bundle, WebAssembly core variants, and
English best_int trained data from Tesseract.js 6.0.1, tesseract.js-core
6.1.2, and @tesseract.js-data/eng 1.0.0. The files are loaded only from this
package after an analyst selects an image; no image bytes or OCR results are
sent to a remote service.
