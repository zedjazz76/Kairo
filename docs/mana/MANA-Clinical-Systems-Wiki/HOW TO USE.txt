EDIT MANUALLY
Open the wiki, select Edit wiki, make the change, and save.
Use Export backup after important manual edits and save the JSON in the backups folder.

SAVE A VERSION MANUALLY
Double-click: Save Version.cmd
This copies the complete site into a timestamped folder under versions and
records a SHA-256 checksum in versions\VERSION-HISTORY.csv.

THIS IS THE ACTIVE VERSION-CONTROL METHOD
Git is not installed on this computer. You do not need it. The complete,
timestamped folders are independent restore points and the checksum history
shows when each version was captured.

ENABLE LOCAL GIT HISTORY — OPTIONAL, ONLY AFTER INSTALLING GIT
Double-click: Enable Git History.cmd
If Git is ever installed later, this creates a local repository and first
commit. Nothing is uploaded. Skip this for the current snapshot workflow.

SAVE A SNAPSHOT
Use Save Version.cmd. Save and Commit Version.cmd also falls back safely to a
normal snapshot when Git is unavailable.
