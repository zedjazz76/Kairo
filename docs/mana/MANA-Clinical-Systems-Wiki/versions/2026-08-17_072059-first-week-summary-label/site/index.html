AMICAS Watch

CONFIRMED MONITORING Operational monitoring and threshold-alerting application for the Merge/AMICAS environment.

Known behavior

  • Associated with the production PACS environment and PACSPROD.
  • Uses threshold-based alerts; a red “receive cancel order” alert was observed when 52 events in one hour exceeded a red threshold of 50.
  • A red condition does not automatically mean PACS is down; it may represent a workflow/event counter crossing a configured threshold.
  • Should be interpreted with monitor name, metric, current value, window, duration, affected node, clinical symptoms and linked logs.
